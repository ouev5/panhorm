## 使用建议

### 微调训练配置
```python
# 推荐配置
base_model = "Qwen/Qwen2.5-7B-Instruct"
# 或
base_model = "THUDM/glm-4-9b-chat"

# 训练参数
epochs = 3-5
learning_rate = 2e-5
batch_size = 8
warmup_ratio = 0.1
```

### RAG系统配置
```python
# 向量数据库
vector_db = "ChromaDB"  # 或 FAISS

# Embedding模型
embedding_model = "BAAI/bge-large-zh-v1.5"

# 检索参数
chunk_size = 500
chunk_overlap = 50
top_k = 5  # 知识库文档增加到10篇，可适当增加
```

### 系统架构
```
用户提问
    ↓
意图识别
    ↓
向量检索(RAG) ← 知识库(10篇文档)
    ↓
检索结果 + 问题
    ↓
微调模型
    ↓
回答生成
    ↓
输出给用户
```

所有数据基于以下项目整理：

- BLAST数据库: 核酸数据库(nt)、蛋白质数据库(nr/swissprot)
- AI服务: DeepSeek API、通义千问视觉API
