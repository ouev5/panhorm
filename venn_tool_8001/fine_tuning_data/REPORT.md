## 使用建议

### 微调训练
```python
# 推荐配置
base_model = "Qwen/Qwen2.5-7B-Instruct"
epochs = 3-5
learning_rate = 1e-5 to 5e-5
batch_size = 4-8
```

### RAG配置
```python
# 推荐配置
vector_db = "ChromaDB"
embedding_model = "BAAI/bge-large-zh-v1.5"
chunk_size = 500
top_k = 3
```

### 系统架构
```
用户提问
    ↓
向量检索（RAG）
    ↓
检索结果 + 问题
    ↓
微调模型
    ↓
回答输出
```
