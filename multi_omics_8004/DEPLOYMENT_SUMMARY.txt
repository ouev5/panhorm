DEPLOYMENT STEPS:

1. Copy files to production:
   cp -r /tmp/multi-omics-work/fixed/* /www/wwwroot/multi-omics/

2. Install dependencies:
   cd /www/wwwroot/multi-omics
   pip install -r requirements.txt

3. Ensure directories exist:
   mkdir -p /www/wwwroot/multi-omics/{data,output,logs}
   chmod 755 /www/wwwroot/multi-omics/{data,output,logs}

4. Run the application:
   python app.py
   # Or with gunicorn:
   gunicorn -w 4 -b 0.0.0.0:8004 app:app
